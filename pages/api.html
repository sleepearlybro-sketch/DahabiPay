Rates API

Rates, reserves and direction limits are published as an XML feed in the layout expected by the common exchanger monitors, so a listing needs no custom integration.

Endpoint

GET https://dahabipay.example/api/v1/rates.xml

Fields

ElementMeaning
from / toCurrency codes of the direction.
in / outRate expressed as a ratio: in units of from give out units of to.
amountAvailable reserve in the receiving currency.
minamount / maxamountLimits on the sending side, with the unit.
fromfeeService fee taken on the sending side.
parammanual for operator-handled directions; absent when automated.
